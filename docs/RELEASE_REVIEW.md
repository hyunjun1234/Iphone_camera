# 버전 0.2.0 검토 결과

검토일: 2026-10-26

한국어 화면과 촬영 및 저장 흐름을 보완했습니다. 자동화 테스트와 에뮬레이터 확인은 통과했지만, 이 결과만으로 갤럭시 실기기에서의 안정성이나 아이폰 색감 재현 정확도가 검증된 것은 아닙니다.

## 이번에 수정한 내용

| 항목 | 발견한 문제 | 반영한 변경 |
| --- | --- | --- |
| 화면 문구 | 영어 제목과 추상적인 홍보 문구, 장식용 구분 기호가 섞여 있었음 | 앱 이름, 메뉴, 스타일 설명, 권한 및 오류 안내를 한국어로 정리하고 실제 동작을 설명하는 문장으로 수정 |
| 색감 설명 | 기종 이름이 실측 보정을 뜻하는 것으로 읽힐 수 있었음 | 스타일 제작 정보와 기종별 출처 링크 추가. XS Max 리뷰와 XS를 구분하고 수치는 직접 정한 값이라고 명시 |
| 사진 방향 | 화면이 세로로 고정돼 있어 가로 촬영 방향을 놓칠 수 있었음 | 센서 방향으로 저장 방향을 갱신하고 방향 경계의 흔들림을 완화 |
| 초점 | 초점 요청 성공 여부를 표시하지 않았음 | 진행과 실패 상태를 표시하고 지원되는 카메라에 초점 고정 및 해제 추가 |
| 촬영 조작 | 볼륨 버튼을 셔터로 사용할 수 없었음 | 설정 추가. 타이머 중 다시 누르면 취소하며 메뉴나 사진 편집 화면에서는 가로채지 않음 |
| 카메라 복구 | 실패한 GPU 처리기를 재사용하거나 준비 전 세션에 촬영을 요청할 가능성 | 세션마다 처리기를 새로 만들고 준비 상태를 확인. 확장 모드 초기화 실패 시 일반 사진 촬영으로 복구 |
| 앱 복귀 | 세션이 닫히면 줌과 노출 설정이 초기화될 수 있었음 | 같은 카메라로 복귀할 때 설정을 복원하고 타이머는 백그라운드 전환 시 취소 |
| 사진 편집 | 스타일을 바꾸는 동안 화면과 저장용 변환표의 갱신 시점이 달랐음 | 두 결과가 준비된 뒤 저장 가능. 투명한 사진은 미리보기와 저장 모두 흰 배경으로 처리 |
| 저장 실패 | 내부 오류 메시지가 그대로 노출되거나 정리되지 않은 임시 파일이 남을 수 있었음 | 한국어 오류 안내, 저장 공간 확인, 작업 실패 시 파일 정리, 오래된 작업 파일 정리 |
| 최근 사진 | 갤러리에서 삭제한 사진의 참조가 남았음 | 앱 복귀 시 접근 여부 확인 후 오래된 참조 제거 |
| 큰 글씨와 작은 화면 | 글자를 키우면 스타일 카드에서 기종명이 가려졌음 | 글자 크기에 따라 카드 크기를 조정하고 작은 화면은 스크롤 지원. 메뉴가 바뀌면 맨 위에서 시작 |
| 배포 빌드 | 코드와 리소스 축소가 설정되지 않았고 후면 카메라 필수 조건이 암묵적으로 적용됨 | 릴리스 최적화 활성화, 불필요한 파일 공유 제공자 제거, 백업 제외 설정 추가. 카메라 하드웨어를 선택 사항으로 선언해 사진 편집만 사용하는 기기도 설치 가능 |

## 기본 카메라 기능과 비교

| 기능 | 현재 앱 | 확인 범위 |
| --- | --- | --- |
| 사진 촬영과 전후면 전환 | 제공 | API 35 에뮬레이터 통합 테스트 |
| 가로와 세로 저장 방향 | 제공 | 방향 계산 단위 테스트, EXIF 8종 변환 테스트, 가속도 센서 입력을 바꾼 릴리스 가로 촬영 |
| 줌과 노출 보정 | 현재 카메라가 공개한 범위 사용 | 지원 범위 감지와 제어 구현. 실기기 렌즈 전환 및 화질은 미검증 |
| 터치 초점과 초점 고정 | 지원되는 카메라에서 제공 | AF 지원과 결과 확인. 노출 고정 기능은 아님 |
| 플래시 | 지원되는 카메라에서 끄기, 자동, 켜기 | 하드웨어 지원 검사. 물리 플래시 동작은 실기기 확인 필요 |
| 볼륨 셔터와 타이머 | 제공 | 촬영, 재입력 취소, 백그라운드 취소 통합 테스트 |
| 격자와 사진 비율 | 제공 | 설정 복원, 3:4 촬영과 1:1 크롭 통합 테스트 |
| 자동 보정, HDR, 야간, 인물 | CameraX Extensions가 지원하는 기기에서 제공 | 미지원 비활성화와 실패 시 복구 구현. 삼성 확장 기능의 실제 결과는 미검증 |
| 초광각과 망원 | 논리 카메라의 공개된 줌 범위에 따라 다름 | 모든 물리 렌즈를 따로 선택하는 기능은 없음 |
| 원본 보관과 편집 | 제공 | 원본 바이트 보존, 색감 적용, 투명 이미지 처리, 손상 파일 거부 테스트 |
| 최근 사진과 공유 | 제공 | MediaStore 저장과 URI 읽기 권한 처리. 외부 갤러리 및 공유 앱별 실기기 확인 필요 |
| 동영상, 연속 촬영, 파노라마 | 미제공 | 이번 버전의 기능 범위 밖 |
| 수동 ISO와 셔터 속도, RAW, 삼성 전용 고화소 모드 | 미제공 | 기본 카메라에서 촬영한 지원 형식의 정지 사진을 가져와 편집 가능 |
| 화면 회전과 태블릿 전용 배치 | 세로 화면 중심 | 작은 화면 스크롤 제공. 폴더블과 태블릿 배치는 추가 검토 필요 |

CameraX 확장 기능은 제조사와 렌즈의 지원 여부에 따라 달라집니다. [Android의 Camera Extensions 문서](https://developer.android.com/media/camera/camera-extensions)

## 실행한 검증

환경은 JDK 21, Android SDK 36, API 35 ARM64 에뮬레이터입니다.

```sh
./gradlew assembleDebug testDebugUnitTest lintDebug connectedDebugAndroidTest bundleRelease assembleRelease
```

- 단위 테스트 10개 통과
- Android 통합 테스트 6개 통과
- 디버그 APK, 최적화된 릴리스 APK, AAB 생성 성공
- 린트 오류 0개. 의존성 업데이트 권장, 세로 화면 고정, 일부 API 사용 등 경고는 남음
- 릴리스 APK를 테스트용 키로 서명한 복사본으로 실행 확인. 볼륨 버튼으로 가로 사진을 촬영해 1280×960 JPG와 EXIF 방향 정규화 확인
- APK의 네트워크 및 위치 권한 없음 확인. 카메라 권한과 Android 9 이하의 저장소 권한 사용
- 한국어 촬영 화면, 색감 조절, 설정과 앱 정보 화면 확인. 글자 크기 130%에서 기종명과 촬영 버튼 접근 확인

테스트용 서명은 생성물 복사본에만 적용했습니다. 배포 서명 설정이나 키를 저장소에 넣지 않았습니다. 에뮬레이터 화면은 [미리보기 이미지](screenshots/camera.png)에서 볼 수 있습니다.

## 출시 전에 남은 확인

1. 지원할 갤럭시 기기와 One UI 버전을 정하고 플래시, 초점 고정, 셀피 반전, 각 촬영 비율과 화면 구도를 검증해야 합니다. HDR, 야간, 인물 모드는 렌즈별 지원과 촬영 실패 후 복구를 확인해야 합니다.
2. 실제 기기에서 장시간 촬영, 발열, 메모리 부족, 저장 공간 부족, 권한 철회, 다른 카메라 앱과의 충돌, 프로세스 종료를 확인해야 합니다. Android 8과 9의 저장 경로도 실제 지원 기기에서 검증해야 합니다.
3. 기종별 색감 재현을 홍보하려면 같은 장면을 갤럭시와 아이폰으로 촬영한 데이터와 별도 평가 결과가 필요합니다. 현재는 [직접 설계한 스타일](COLOR_EVIDENCE.md)이라는 설명을 유지해야 합니다.
4. 운영자명과 문의처, 공개된 개인정보처리방침 주소, 배포용 서명을 준비해야 합니다. 현재 앱 안의 데이터 처리 설명은 운영자 정보가 갖춰진 배포용 개인정보처리방침을 대신하지 않습니다. 스토어 설명과 데이터 보안 항목도 실제 동작에 맞춰 작성해야 합니다.

브랜드 이름으로 공식 앱처럼 보이게 하거나 실제로 없는 기능을 광고하지 않도록 스토어 표시도 검토해야 합니다. 관련 기준은 [Google Play 사칭 정책](https://support.google.com/googleplay/android-developer/answer/9888374?hl=en)과 [사용자 데이터 정책](https://support.google.com/googleplay/android-developer/answer/10144311?hl=en)에서 확인할 수 있습니다.
